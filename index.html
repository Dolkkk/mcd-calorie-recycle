参赛作品 · 非麦当劳官方产品 热量为估算值 不构成营养建议

麦麦热量回收计划 · 麦当劳程序员创意开发大赛参赛作品，由参赛者独立开发。
餐品营养数据与门店信息来自麦当劳中国 MCP Server 官方接口；路线由 OpenStreetMap / OSRM 计算，卡路里按 MET 公式估算。
本项目输出仅供参考，不构成医疗、营养或其他专业建议；餐品信息及供应状态以麦当劳官方渠道实时结果为准。
